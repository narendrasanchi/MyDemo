A demonstration of Amazon Connect chat widget integration with Angular

Features

  • ✅ Dynamic loading of Amazon Connect chat script
  • ✅ Configurable environment settings
  • ✅ Responsive design for mobile and desktop
  • ✅ Error handling and user feedback
  • ✅ Toggle chat window functionality

Configuration

To use this demo with your Amazon Connect instance:

  1. Update src/environments/environment.ts with your CloudFront URL
  2. Set your Amazon Connect snippet ID in the environment file
  3. Configure your Connect instance URL (optional)
  4. Click the chat button in the bottom-right corner to test

Testing

The chat widget button is located in the bottom-right corner of the page. Click it to:

  • Load the Amazon Connect chat interface
  • Connect to your configured Connect instance
  • Start a customer support conversation

Note: You need a properly configured Amazon Connect instance and valid snippet ID for the chat to function.
